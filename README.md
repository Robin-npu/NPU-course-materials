# NPU-course-materials
## 西北工业大学计算机学院计算机科学与技术专业的一些课程资料，欢迎大家下载参考，记得点个star~

本资料包旨在为计算机科学与技术专业的同学提供一些课程资料参考，现在的大学教育已然落后于时代，大部分课程与就业要求脱节严重，希望大家能借助这些资料节省自己学习课内知识的时间，能够抽出更多时间学习一些前沿的知识，为以后的就业打好基础。

叠甲：本资料包均为我自己收集的一些课件，电子课本，课后习题答案等以及我自己的实验报告，课程大作业等，仅供参考，不敢保证能拿高分。同时，可能会有很多人参考我的资料，由抄袭发生的一系列问题本人概不负责，请大家注意。

本资料包分为三个部分，第一个是通识课程，包括微积分，线性代数，概率论，大学物理等学科通识课程；第二个是计算机科学与技术专业课程，里面包括408这种专业课程，以及一些计算机学院开设的专业选修课程；第三个是选修课程，包括其他学院开设的一些素养课程，也即是大家常说的“水课”。
