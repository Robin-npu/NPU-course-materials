## 五、实验内容

### 1.跑马灯设计及FPGA实现(run.v)

##### (0)电路原理分析

`clk`: 时钟信号。
`rst`: 异步复位信号，低电平有效。
`out`: 8位输出，用于控制8个LED的状态。

- 内部寄存器`count`: 25位计数器，用于分频和控制LED的状态变化。在计数器逻辑上：在每个时钟上升沿或复位的下降沿触发。如果 `rst` 为低，计数器重置为0。否则，计数器递增。

- LED控制逻辑:同样在时钟上升沿或复位的下降沿触发.如果 `rst` 为低，`out` 寄存器初始化为 `8'hff`(所有LED亮).根据 `count[24:21]` 的值，选择不同的LED模式： 从 `0` 到 `7`，逐个熄灭LED.从 `8` 到 `14`，按相反顺序再次熄灭LED.在 `15` 时，所有LED亮.

##### (1)模块源码

```verilog
//跑马灯设计源码
module run (clk,rst,out); 
    input clk,rst; 
    output [7:0] out; 
    reg [7:0] out; 
    reg [24:0] count; 
    always @ ( posedge clk or negedge rst ) 
        if(!rst) 
        begin 
            count<=16'b0; 
        end 
        else 
        begin 
            count<=count+1; 
        end 

    always @ ( posedge clk or negedge rst) 
        if(!rst) 
        begin 
            out<=8'hff; 
        end 
        else 
        begin 
            case ( count[24:21] ) 
                0: out<=8'b1111_1110; 
                1: out<=8'b1111_1101; 
                2: out<=8'b1111_1011; 
                3: out<=8'b1111_0111; 
                4: out<=8'b1110_1111; 
                5: out<=8'b1101_1111;             
                6: out<=8'b1011_1111; 
                7: out<=8'b0111_1111; 
                8: out<=8'b1011_1111;
                9: out<=8'b1101_1111; 
                10:out<=8'b1110_1111; 
                11:out<=8'b1111_0111; 
                12:out<=8'b1111_1011; 
                13:out<=8'b1111_1101; 
                14:out<=8'b1111_1110; 
                15:out<=8'b1111_1111; 
            endcase 
        end 
endmodule 

```

### 2.有限状态机设计及仿真（以教材Figure 6.86为例）

##### (0)电路原理分析
这是一个有限状态机,在代码中首先使用parameter进行状态分配,然后依据w,y的取值使用case和if-else进行状态转移即可,最后根据状态输出即可.

##### (1)需求解读
_设计一个带有输入w的,输出z的有限状态机,功能上是一个序列检测器,当w=00或11时,输出z=1,否则为0._
这是状态转移图,依据此图就可以进行代码编写了
![alt text](Screenshot_20241209_152423_com.orion.notein.png)
##### (2)模块源码

```verilog
module FSM(CLK, Resetn, w, z);
    input CLK, Resetn, w;
    output z;
    reg [3:1]y, Y;
    parameter [3:1]A = 3'b000, B = 3'b001, C = 3'b010, D = 3'b011, E=3'b100;
    always @(w,y) 
    begin
        case(y)
            A:if(w) Y=D;
            else Y = B;
            B:if(w)Y = D;
            else Y = C;
            C:if(w) Y = D;
            else Y = C;
            D:if(w) Y = E;
            else Y = B;
            E:if(w) Y = E;
            else Y = B;
            default: Y = 3'bxxx;
        endcase
    end
    always @(negedge Resetn, posedge CLK)
        if (!Resetn)
            y <= A;
        else y <= Y;
    assign z = (y ==C ) | (y == E);
endmodule
```

##### (3)测试模块

```verilog
module FSM_tb;
    reg CLK, Resetn, w;
    wire z;
    FSM uut (
        .CLK(CLK),
        .Resetn(Resetn),
        .w(w),
        .z(z)
    );
    
    initial 
    begin
        CLK = 0;
        forever #5 CLK = ~CLK;  // 每5个时间单位切换时钟
    end

    initial
    begin
        // 初始化输入
        Resetn = 0;
        w = 0;
        // 应用复位
        #10 Resetn = 1;
        // 状态测试序列
        #10 w = 0;  // A -> B
        #10 w = 0;  // B -> C
        #10 w = 1;  // C -> D
        #10 w = 1;  // D -> E
        #10 w = 0;  // E -> B
        #10 w = 1;  // B -> D
        #10 w = 0;  // D -> B
        repeat (20) 
        begin
            #20 w = $random % 2;  // 每20个时间单位随机分配w
        end
        // 结束仿真
        #200 $stop;
    end
endmodule
//测试思路是首先通过人为给定的状态转移思路来测试,随后使用随机的方法来继续测试.
```

##### (4)波形图及其分析
![alt text](image-19.png)
**初始状态（复位）**：
从黄线的位置开始,就是复位结束的地方,当 `Resetn` 为低时，状态机初始化为状态 `A`。

**状态转移序列**：
- **时刻 15ps**：
    - `w = 0`，状态从 `A` 转移到 `B`。
- **时刻 25ps**：
    - `w = 0`，状态从 `B` 转移到 `C`。
- **时刻 45ps**：
    - `w = 1`，状态从 `C` 转移到 `D`。
- **时刻 55ps**：
    - `w = 1`，状态从 `D` 转移到 `E`。
- **时刻 65ps**：
    - `w = 0`，状态从 `E` 转移到 `B`。
- **时刻 75ps**：
    - `w = 1`，状态从 `B` 转移到 `D`。
- **时刻 85ps**：
    - `w = 0`，状态从 `D` 转移到 `B`。

**输出 `z` 的变化**：
   - `z = 1` 当状态为 `C` 或 `E`。
   - 因此，在时刻 25~45ps 和 55~75ps这两个时段，`z` 输出为 1。
以上是在代码中有目的的进行的状态转移,随后是使用随机过程得出的w的输入,经过分析后续过程依旧符合状态转移图,因此该电路的设计是正确的.
