## 一、系统概述
### 1.1 指令集系统结构
#### 1.1.1 目标指令集介绍
本设计实现一个简化的MIPS单周期处理器，仅支持以下五条指令：

表1 典型指令描述
| 指令名称 | 指令类型(I/R) | 核心功能描述 |
| :------- | :------------ | :----------- |
|  ORI       | I型           |寄存器与立即数按位或 |
| ADDU        | R型    |  无符号加法    |
| LW       | I型    |  从内存加载数据   |
| SW      | I型    |  向内存存储数据   |
| BNE     | I型    |  不等时分支跳转  |

#### 1.1.2处理器系统结构类型概述
本设计采用**单周期处理器结构（Single-Cycle CPU）：**
* 每条指令在一个时钟周期内完成
* 无流水线，无冒险处理
* 控制简单，结构清晰，适合学习与验证

### 1.2功能与性能
#### 1.2.1系统功能概述
本处理器支持：
* 基本算数运算（ADDU）
* 逻辑运算（ORI）
* 存储访问（LW / SW）
* 条件分支（BNE）
#### 1.2.2系统性能概述
* CPI = 1（每条指令一个周期）
* 时钟周期由最长路径决定（访存路径）
* 结构简单但性能较低

### 3.2核心模块详细设计
#### 3.2.1 寄存器堆（GPR）与写回逻辑设计
描述处理器的通用寄存器堆（Register File）及其状态更新机制。

**（1）设计功能与处理方法**
本处理器内部实现了 32 个 32 位宽的通用寄存器 `GPR [0:31]`。其处理方法如下：
* **读操作**：采用异步组合逻辑读。直接根据指令译码出的 `rs` 和 `rt` 索引读取对应的寄存器数据。
* **写操作**：采用同步时序逻辑写。在 `clk` 上升沿，根据当前 `opcode` 决定将 `alu_out` 或外部 `dmem_rdata` 写入 `rt` 或 `rd` 对应的寄存器。
* **$0 寄存器保护**：软件规约规定 `$zero` 恒为 0。在 RTL 设计中，通过在每次写回时判定目标寄存器不为 0，且在时钟沿末尾强行赋值 `GPR[0] <= 32'b0` 来确保硬件级别的只读 0 特性。

**（2）状态机设计（单周期组合/次态逻辑）**
单周期处理器不包含复杂状态机，但寄存器写回遵循以下多路分支判断逻辑：
* 当 `opcode == 6'b001101` (ORI)，若 `rt != 0`，写回 `alu_out`。
* 当 `opcode == 6'b000000` 且 `funct == 6'b100001` (ADDU)，若 `rd != 0`，写回 `alu_out`。
* 当 `opcode == 6'b100011` (LW)，若 `rt != 0`，写回 `dmem_rdata`。

**（3）存储单元的位宽深度设计**
* **位宽**：32 位（符合 MIPS 标准字长）。
* **深度**：32 个（寻址范围为 5 位，即 $0 ~ $31）。

**（4）内部信号设计与时序图**
当复位信号 `rst_n` 拉低时，触发异步复位，循环将 32 个寄存器全清零。正常工作时，写使能信号随指令在单周期内译码产生，在时钟上升沿完成写入。

#### 3.2.2 ALU 与分支跳转模块设计
**（1）设计功能与处理方法**
ALU 负责执行所有的算术和逻辑运算。由于是单周期设计，ALU 纯粹由组合逻辑 case 语句实现：
* **ORI**：将 `GPR[rs]` 与 16 位零扩展的立即数 `imm_zero` 进行按位或。
* **ADDU**：将 `GPR[rs]` 与 `GPR[rt]` 进行无符号加法。
* **LW / SW**：将 `GPR[rs]` 与 16 位符号扩展的立即数 `imm_ext` 进行加法，计算内存物理地址。

分支跳转逻辑（BNE）根据 `GPR[rs]` 与 `GPR[rt]` 的不等比较结果产生 `bne_taken` 信号。若成立，则 `next_pc` 被计算为 `PC + 4 + (imm_ext << 2)`，实现在下一个周期边缘完成跳转。

**（2）状态机设计（次态逻辑）**
PC 的次态逻辑表示为纯组合反馈：
`next_pc = bne_taken ? (PC + 4 + (imm_ext << 2)) : (PC + 4)`

**（3）存储单元设计**
该模块为纯组合逻辑电路，内部不包含独立的存储状态元件（其状态暂存在顶层 PC 寄存器中）。

**（4）内部信号设计与时序图**
在单周期内，指令机器码一经到来，ALU 立即开始进行电平传导计算。为了防止冒险，其输出必须在时钟周期结束前（Setup Time 之内）稳定。

## 四、总结
本项目成功实现了一个具备基础功能的 MIPS 单周期处理器。通过合理的模块化设计，确保了指令在单时钟周期内能正确流转。重点解决了 `BNE` 的分支计算路径以及 `GPR[0]` 的写保护逻辑 ，为后续 `Phase 2` 的多周期或流水线设计打下了坚实基础。
